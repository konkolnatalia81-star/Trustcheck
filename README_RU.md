# TRUST CHECK 2.0

Сайт с 24 ситуационными вопросами. Все отправленные результаты хранятся в Supabase; доступ к просмотру результатов защищён серверным секретным кодом.

## Важно
- Никогда не публикуйте `ADMIN_CODE`, `SESSION_SECRET` или `SUPABASE_SERVICE_ROLE_KEY`.
- Не добавляйте секреты в GitHub или HTML.
- Это не научный тест и не диагноз.
- Не собирайте фамилии, адреса, телефоны и другие личные данные участников.

## База данных Supabase
1. Создайте проект Supabase.
2. Откройте SQL Editor.
3. Скопируйте `supabase_schema.sql` и выполните SQL.
4. Сохраните Project URL и service_role key. Service role key нельзя никому отправлять и нельзя вставлять в HTML.

## Размещение на Render
Создайте Web Service из GitHub-репозитория:
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`

Добавьте переменные окружения:
- `SUPABASE_URL` = Project URL
- `SUPABASE_SERVICE_ROLE_KEY` = service_role key
- `ADMIN_CODE` = ваш секретный код
- `SESSION_SECRET` = длинная случайная секретная строка

После добавления переменных запустите Deploy.

## Оценка
«Да» = положительное наблюдаемое поведение, «Нет» = отрицательное. Процент рассчитывается по вопросам с ответами «Да» и «Нет». «Свой вариант» сохраняется для просмотра администратором, но не получает автоматических баллов.
